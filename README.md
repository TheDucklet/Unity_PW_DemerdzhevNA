================================================================================
                    3D TREASURE HUNTER (UNITY 6 + AR + NGO)
================================================================================
Трехмерный приключенческий экшен с процедурной генерацией, физическим контроллером,
интеллектуальными противниками на NavMesh, сетевым P2P-мультиплеером на Netcode
for GameObjects и поддержкой дополненной реальности (AR Foundation).

Разработчик: Никита Демерджев (РТУ МИРЭА, ИИТ, каф. ИППО)
GitHub: https://github.com/theducklet
Telegram: @theducklet

--------------------------------------------------------------------------------
1. ОБЗОР ПРОЕКТА
--------------------------------------------------------------------------------
«3D Treasure Hunter» — кроссплатформенная игра, в которой игрок исследует
арену-подземелье, собирает сокровища и зелья здоровья, управляет шкалой выносливости
(спринт) и избегает столкновений со стражем (EnemyGuardian), управляемым ИИ.

Проект прошел полный цикл разработки от базового физического прототипа до
полнофункционального приложения с сетевой синхронизацией и AR-режимом
(проецирование 3D-арены на реальный стол или пол).

--------------------------------------------------------------------------------
2. ТЕХНИЧЕСКИЙ СТЕК И АРХИТЕКТУРА
--------------------------------------------------------------------------------
• Движок: Unity 6 (Universal Render Pipeline - URP)
• Язык: C# (.NET Standard / Unity API)
• Физика: Rigidbody, CapsuleCollider, BoxCollider, кинематические ограничения
• Навигация и ИИ: AI Navigation (NavMesh, NavMeshSurface, NavMeshAgent, A*)
• Пользовательский интерфейс: Unity UI (Canvas Scaler, TextMeshPro, Sliders)
• Анимация:
  - Ключевая: Unity Animation Clip (.anim), Animator Controller (State Machine)
  - Процедурная: Математический расчет синусоиды (Mathf.Sin) и интерполяция (Lerp)
• Графика и VFX: Particle System (Burst / Ambient излучатели), URP Lit Shaders
• Аудио: Менеджер-синглтон (AudioManager, DontDestroyOnLoad, 2D/3D AudioSource)
• Сеть: Unity Netcode for GameObjects (NGO), UnityTransport, RPC (ServerRpc/ClientRpc)
• Дополненная реальность: AR Foundation, ARCore / ARKit, XR Origin, AR Raycast Manager

--------------------------------------------------------------------------------
3. КЛЮЧЕВЫЕ СИСТЕМЫ И МОДУЛИ
--------------------------------------------------------------------------------

[1] ФИЗИЧЕСКИЙ КОНТРОЛЛЕР И СОСТОЯНИЕ ИГРОКА (PlayerController.cs, PlayerStats.cs)
• Движение через Rigidbody.MovePosition() в цикле FixedUpdate() исключает
  проваливание сквозь коллизии стен и препятствий.
• Плавный поворот персонажа к вектору движения через Quaternion.Slerp().
• Система выносливости (Stamina System):
  - Обычная скорость (WalkSpeed = 5.0) и спринт (SprintSpeed = 9.0).
  - Динамический расход энергии при удержании LeftShift и авторегенерация.
• Инкапсулированное управление здоровьем (Health) и счетом (Score).

[2] ООП-АРХИТЕКТУРА ПРЕДМЕТОВ (CollectableItem.cs, CoinItem.cs, HealthPotionItem.cs)
• Базовый абстрактный класс CollectableItem с триггерной обработкой (OnTriggerEnter).
• Полиморфный абстрактный метод OnCollect(PlayerStats player):
  - CoinItem: начисление очков (+10).
  - HealthPotionItem: восстановление здоровья (+25 HP).
• Процедурный спавнер (ItemSpawner.cs): динамический рандомный спавн префабов
  в заданном полигоне координат (X, Z) методом Instantiate().

[3] ИСКУССТВЕННЫЙ ИНТЕЛЛЕКТ И НАВИГАЦИЯ (EnemyAI.cs)
• Запеченная трехмерная сетка проходимости NavMeshSurface на арене.
• Преследование игрока агентом NavMeshAgent с автообходом статических препятствий.
• Расчет дистанции атаки (AttackRange) и таймер перезарядки (AttackCooldown).
• Нанесение урона игроку с вызовом звуков и анимаций удара.

[4] АДАПТИВНЫЙ ИНТЕРФЕЙС, ХУД И ПАУЗА (HUDController.cs, PauseMenuController.cs)
• Адаптивный HUD (Canvas Scaler: Scale With Screen Size 1920x1080):
  - Слайдер здоровья (HealthBar) и слайдер выносливости (StaminaBar).
  - Динамический счетчик собранных сокровищ на базе TextMeshPro.
• Меню паузы (Escape):
  - Полная остановка физического мира (Time.timeScale = 0f).
  - Кнопки продолжения, перезапуска уровня и выхода в Главное Меню.
• Межсценная передача данных (GameData.cs): статический класс для сохранения
  последнего счета и рекорда между MainScene и MainMenuScene.

[5] ВИЗУАЛЬНЫЕ ЭФФЕКТЫ И ЗВУКОВОЙ СИНГЛТОН (AudioManager.cs, ProceduralAnimator.cs)
• Системы частиц (Particle System):
  - Фоновое мерцание золотых искр (CoinSparkles) вокруг несобранных предметов.
  - Разовый взрывной салют (Burst CollectFX) в точке сбора.
• Процедурная анимация: покачивание 3D-моделей по синусоиде и плавное
  увеличение UI-кнопок при наведении курсора (IPointerEnter / IPointerExit).
• Аудио-менеджер: независимые каналы Music/SFX, глобальная фоновая музыка,
  звуки сбора монет, ударов и кликов меню.

[6] P2P СЕТЕВОЙ МУЛЬТИПЛЕЕР (NetworkP2PManager.cs, NetworkPlayerData.cs)
• Архитектура Host/Client на базе Unity Netcode for GameObjects.
• Пользовательский бинарный пакет PTS (PlayerTrackingState) с интерфейсом
  сериализации INetworkSerializable (передача координат, поворота, очков и HP).
• Синхронизация между клиентами через связку ServerRpc и ClientRpc с интерполяцией
  (Vector3.Lerp / Quaternion.Slerp) для компенсации сетевого лага.

[7] РЕЖИМ ДОПОЛНЕННОЙ РЕАЛЬНОСТИ (ARPlaceArenaController.cs)
• Определение реальных горизонтальных поверхностей через AR Plane Manager.
• Выпуск AR-лучей (ARRaycastManager) по тапу на экране смартфона.
• Проецирование настольной масштабированной копии 3D-арены в реальный мир.

6. ИНСТРУКЦИЯ ПО СБОРКЕ И ЗАПУСКУ
--------------------------------------------------------------------------------
1) Открытие проекта:
   - Запустите Unity Hub и добавьте проект (рекомендуется Unity 6 / 2023.3+).
   - Убедитесь, что активен конвейер Universal Render Pipeline (URP).

2) Пакеты (Package Manager -> Unity Registry):
   - Netcode for GameObjects
   - AI Navigation (NavMesh)
   - TextMeshPro
   - AR Foundation (для сборки под мобильный AR)
   - OpenXR / Google ARCore XR Plugin / Apple ARKit XR Plugin

3) Конфигурация сцен (Build Profiles / Build Settings):
   - Индекс 0: Assets/Project/Scenes/MainMenuScene.unity
   - Индекс 1: Assets/Project/Scenes/MainScene.unity

4) Запуск в Редакторе:
   - Откройте MainMenuScene и нажмите Play Mode.

5) Сборка:
   - Для ПК: выберите платформу Windows/macOS/Linux -> Build.
   - Для AR: переключитесь на платформу Android/iOS, проверьте настройки XR Plugin
     Management (ARCore/ARKit) и соберите .apk/.ipa.
